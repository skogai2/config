# zsh

zsh 5.9.2. Rebuilt 2026-11-23 as the basics: oh-my-zsh + mise + atuin
(skogix). Not the login shell (fish is); used by typing `zsh`.

## files

- `~/.zshenv`: only `export ZDOTDIR="$HOME/.config/zsh"`.
- `~/.config/zsh/.zshrc`: everything else. History in
  `$ZDOTDIR/.zsh_history`, omz cache and compdump in `~/.cache/oh-my-zsh/`.
- Both tracked by mise dotfiles (`~/.config/mise/conf.d/dotfiles-tracking.toml`),
  `.zsh_history` excluded.

## ~/.config/zsh/.zshrc, in order

1. oh-my-zsh from the AUR package `oh-my-zsh-git` (`/usr/share/oh-my-zsh`),
   declared as `aur:oh-my-zsh-git` in `[bootstrap].packages`. Stock
   `robbyrussell` theme, `plugins=(git vi-mode vim-interaction mise)`; the
   `mise` plugin runs `mise activate zsh` and writes `_mise`.
   `DISABLE_AUTO_UPDATE`: yay updates it. `ZSH_CACHE_DIR` must be set,
   `/usr/share` isn't writable. omz brings the options, history settings,
   compinit and keybindings.
2. `ZSH_CUSTOM="$ZDOTDIR"`: omz picks up `completions/` and `functions/`
   (fpath, `oh-my-zsh.sh:76`), sources every `*.zsh` after the plugins
   (`:322`, a built-in zsh.d), and `plugins/<name>/`, `themes/` (`:91`, `:335`).
3. `atuin init --disable-up-arrow zsh`: atuin owns ctrl-r, the up arrow stays
   with zsh (skogix, 2026-11-23).

Startup ~160ms (`zsh -ic exit`, 2026-11-23).

## completions

Still fpath + compinit: a `_cmd` file with `#compdef cmd` in a dir on
`$fpath`. omz puts `~/.cache/oh-my-zsh/completions` first on fpath
(`oh-my-zsh.sh:66-68`).

- Hand-written or vendored: `$ZDOTDIR/completions/`, tracked with the rest.
- Generated by the tool itself (`atuin gen-completions --shell zsh` etc.):
  `~/.config/zsh/gen-completions` writes them to the cache dir, not tracked
  (they'd change on every upgrade). Run by mise's global
  `[hooks].postinstall` in `~/.config/mise/config.toml`, so every
  `mise install`/`upgrade` refreshes them; global hooks fire in every dir
  (mise `src/hooks.rs:331`). `mise install` with nothing to install still
  runs it. A file is regenerated only when the binary is newer.
- Adding a tool: one line in the script's `gens` list. Checked
  2026-11-23: atuin, fnox, gh, herdr, rg, usage, uv. fzf, lazygit and
  zoxide print no `#compdef` file. mise is the omz plugin's.
- Gotcha: a new file in a dir already on fpath doesn't invalidate omz's
  dump (omz only compares the fpath list, `:215-223`); the script deletes
  `~/.cache/oh-my-zsh/zcompdump*` when it wrote something.
