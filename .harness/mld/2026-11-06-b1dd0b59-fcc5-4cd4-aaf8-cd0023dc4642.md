## Mistakes
- Used `${PIPESTATUS[0]}` in a Bash call; the tool shell is zsh, so it printed empty. Use a
  separate `; echo $?` without a pipe.
- Wrote the first F001 spec without verbatim samples of the outputs it parses; the spec gate
  needed two rounds.

## Learnings
- `mise doctor` exits 1 on problems and prints env/settings; parse only the problems block.
- Capture a timed-out child's output to a file, not a pipe, or orphaned grandchildren block.
- A minimal PATH toolbox (symlinked basics) makes "command not found" branches testable when
  the real command lives in /usr/bin.
